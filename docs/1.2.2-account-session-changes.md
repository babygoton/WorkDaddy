## 账号和主题

- 保留历史 `default` 配置键，显示为「浅色」；新增 `dark` 显示为「深色」。两者同步 WorkBuddy 原生外观存储及根属性，移除自定义色板/壁纸，并保留重载恢复和单一主题 observer。
- 账号页移除主账号设置按钮及徽标；既有自动化后台接口保留兼容。
- 签到分别显示高亮的「今日已签到」和灰色的「今日未签到」，AI 客户端仍不显示国内签到功能。
- 账号排序模式存于各 profile 的 `meta.json.accountOrderMode`，固定顺序存于 `accounts[uid].sort`。正整数升序，缺省/0 在最后；删除账号沿用原有元数据清理。拖拽或方向键调整后点击保存；取消不写入。
- 总积分旁新增汇总图标，悬浮/聚焦展示按每个积分段的剩余天数聚合的条形图。剩余天数按 24 小时向上取整，已到期单列，未知有效期不展示；读取失败、登录过期和不限量账号不伪造余额，另显示数量。

## 面板细节与头像

- 汇总进度条与账号积分段共用浅色/深色颜色规则，透明度按剩余天数线性计算：≤1 天为 0.05，≥30 天为 1，中间为 0.05 + 0.95 × (天数 − 1) / 29。
- 账号排序入口改为排序 SVG 图标；弹窗在插件面板内居中，固定列表显示明文账号，移除说明段落和序号，保留拖拽/键盘调整。
- 主题按钮改用 `data-wbs-theme-option`，避免官方 `[data-theme="dark"]` 规则把单个按钮变为深色区域；悬浮机器人选项复用主题分段按钮样式。
- 头像提供 WorkBuddy、WorkDaddy 预设，保留上传及旧自定义头像缓存，移除恢复默认按钮。用户提供的 WorkDaddy SVG 原样存于 `scripts/assets/workdaddy-app-icon-source.svg`。
- 隔离 renderer 验证了汇总条与账号条计算颜色一致、主题/机器人分段样式一致、明文排序及面板居中、390px 布局、头像图片加载与重新注入后保留选择。

## 删除目录兼容

旧实现从配置的数据根开始逐级 lstat，根目录自身是 Windows junction 或目录符号链接时也会拒绝。删除边界先 realpath 配置根，再沿真实根逐级检查 managed parent；内部目录链接仍然拒绝，叶子链接只删除链接本身。会话 ID 校验和先文件后数据库的删除次序保持不变。

回归覆盖真实目录链接作为配置根、内部链接拒绝、同源副本级联删除及缓存写入失败。此处在 macOS 用目录符号链接验证了同类失败，不代表已在用户 Windows junction 上实测。

## 产物复制原因与修复

只读检查本机 WorkBuddy.app 的官方代码发现：`main/conversations.js` 的 `ConversationImpl.filterArtifactsOwnedByConversation` 对工作目录外的 PresentFiles 产物要求 `_meta.ownerConversationId` 匹配当前会话。原先复制 `artifact-index/<id>.json` 只改文件名，内部 owner 仍为原会话，因此切号副本中的文件被官方过滤。

复制时只把源会话或已记录同源 lineage 的 owner 改为目标 ID，保留 requestId、URI 和其他会话的 owner。已有副本作为最新来源时也修复自身旧 owner。读取失败或格式错误不覆盖目标，不在错误中输出索引正文；就地修复发现官方并发写入时保留新数据。

同时保留所有复制载荷的原始文件时间。`selectLatestAutoCopyMember` 使用内容 mtime，原先复制动作会制造较新的 mtime，可能把旧副本选为下一轮同步来源。

没有改变官方会话 RPC、打开顺序、官方安装文件或普通账号切换的 JSON 替换 + CDP reload 流程。
